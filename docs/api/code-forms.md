# 耗材码制与归一口径（UDI / GS1 AI(01) / 院内码）

> 扫码枪扫出来的码长什么样、怎么归一到院内耗材主数据键、什么情况算「码本身有问题」。

扫码枪扫出来的码可能是三种形态，**码段结构、校验位与主数据键都不一样**：

| 码制 | 长什么样 | 举例 | 归一后的主数据键 |
|------|----------|------|------------------|
| `UDI` | 带 GS1 应用标识符（`(01)` 器械标识、`(10)` 批号、`(17)` 失效期、`(21)` 序列号） | `(01)06912345678902(10)LOT-A1)` | 取 `(01)` 的 14 位 DI |
| `GS1_AI01` | 裸 `01` + 14 位 GTIN 的包装码（只有器械标识） | `0106987654321092` | 取 `01` 之后的 14 位 GTIN |
| `INTERNAL` | 院内自编码（不走 GS1 规则） | `MAT-SAMPLE-01` | 原样（去空白） |

## 一条码怎么被解析

```
扫码枪原始码
   │
   ├─ 形态识别 ──→ UDI / GS1_AI01 / INTERNAL
   │
   ├─ GS1 族：拆应用标识符 ──→ DI（器械标识）/ PI（生产标识：批号 / 序列号 / 失效期）
   │        │
   │        └─ GTIN 校验位核对（GS1 mod-10）──→ 相符 / 不符（独立错误码）
   │
   ├─ 归一 ──→ 院内耗材主数据键（DI / 裸 GTIN / 原样）
   │
   └─ 字典映射 ──→ 主数据里有没有这个键 ──→ 有 → 继续判定；没有 → 耗材未建档
```

## GTIN 校验位（GS1 mod-10）

校验位按 GS1 标准计算：**最右边的数据位乘 3，逐位向左 3 / 1 交替**。
GTIN-14 的数据位有 13 位（奇数），所以从左往右看是 3,1,3,1,…,3 —— **首位乘 3**。

| 码 | 校验位 |
|----|--------|
| `5901234123457`（GTIN-13 教材例） | 7 |
| `00012345600012`（GTIN-14 教材例） | 2 |
| `06912345678902` | 2 |

**校验位不符 → 独立错误码，不与「耗材未建档」混同**：

| 情形 | 原因码 | 统一错误码 | 处置口径 |
|------|--------|------------|----------|
| GS1 码里的 DI 校验位不符 | `CODE_GTIN_CHECK_DIGIT_INVALID` | `ERR_GTIN_CHECK_DIGIT_INVALID` | 重扫一次；仍不符则条码破损或扫到的不是耗材码，转人工核对实物 |
| 裸 14 位码校验位不符且主数据查不到 | `CODE_GTIN_CHECK_DIGIT_INVALID` | `ERR_GTIN_CHECK_DIGIT_INVALID` | 同上（**不是**补档案） |
| 校验位对但主数据查不到 | `MATERIAL_NOT_REGISTERED` | `ERR_MATERIAL_NOT_REGISTERED` | 由高值耗材管理岗补建档 |
| GS1 码里取不到器械标识（DI） | `CODE_DI_MISSING` | `ERR_CODE_DI_MISSING` | 核对设备侧码制配置；确认扫到的是带 `(01)` 的包装码 |

> **院内码不做校验位判定**：院内自编码的末位不一定是 GS1 校验位，拿 GS1 的尺子量院内码会误伤。

## DI / PI 分离

| 应用标识符 | 含义 | 用途 |
|------------|------|------|
| `(01)` | 器械标识（DI，14 位 GTIN） | 归一到院内主数据键 |
| `(10)` | 批号（生产批） | **进入 v2 幂等键维度**（同码不同批各算一次） |
| `(17)` | 失效期 | **只落类别**，不落具体日期 |
| `(21)` | 序列号 | 落解析轨迹供核对 |

失效期只保留四个类别：`long_term`（无 `(17)` 段，长期有效）/ `has_expiry`（有失效期）/ `expired`（已过期）/ `unknown`（读不出来）。
**解析轨迹与台账里都不写具体日期** —— 原始码按设备上报的原样保留，那是设备的事实；本系统自己落的只有类别。

## 解析轨迹（落台账）

台账行同时保留三样东西，事后能逐条复核「这个码当时是怎么被解析的」：

| 字段 | 内容 |
|------|------|
| `raw_code` | 设备上报的原始码（原样） |
| `code_form` | 码制：`UDI` / `GS1_AI01` / `INTERNAL` |
| `code_parse_trace` | 解析轨迹 JSON：归一来源、DI、批号、序列号、失效期类别、GTIN 校验位核对结论、码段清单、解析问题 |
